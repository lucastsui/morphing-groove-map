# Groove Player

Stamp a drum groove onto a straight loop and play it in the browser.

- **Google Groove Dataset** grooves (extracted from the [Groove MIDI Dataset](https://magenta.tensorflow.org/datasets/groove), CC-BY 4.0)
- **Analyze the Amen break** into your own swing file
- A **swing-amount dial** morphs from straight (0) to full groove (127)

Source & docs: <https://github.com/lucastsui/morphing-groove-map>
